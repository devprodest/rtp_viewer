= RTP Viewer — приём и отображение несжатого RTP видео
:toc: macro

toc::[]

== Описание

Программа принимает RTP-пакеты по UDP согласно RFC 4175, собирает кадры и отображает их в окне OpenGL. Поддерживаются различные пиксельные форматы, настраиваемые через внешние файлы в папке `formats/`. Реализована двойная буферизация кадров.

== Аргументы командной строки

Обязательные:

`-x <width>`:: ширина видео (пиксели).
`-y <height>`:: высота видео.
`-p <port>`:: UDP-порт (IPv4).
`-f <format>`:: имя формата (`gray8`, `rgb888`, `bayerRGGB` и т.п.).

Опциональные:

`-e <bits>`:: эффективные биты для `gray16` (по умолчанию 16).
`-s <prefix>`:: префикс имён файлов для сохранения сырых кадров.
`-b <N>`:: количество кадров в одном файле (по умолчанию 1).
`-t <seconds>`:: интервал сохранения в секундах (0 — без ограничения).
`-l <logfile>`:: файл для статистики с меткой времени.
`-o <dir>`:: директория сохранения (по умолчанию текущая).
`-S`:: включить сглаживание при старте.
`-h`:: справка.

== Горячие клавиши

`S`:: переключить сглаживание.
`R`:: вкл/выкл запись.
`W`:: принудительно сохранить накопленные кадры.
`Esc`:: выход.

== Форматы

Каждый формат описывается двумя файлами:

. `formats/<name>.fmt` — конфигурация.
. `formats/<name>.glsl` — фрагментный шейдер.

=== Файл `.fmt`

Формат — пары `ключ = значение`, комментарии начинаются с `#`.

`bytes_per_pixel`:: размер пикселя в байтах.
`gl_internal_format`:: внутренний формат OpenGL.
`gl_format`:: формат данных.
`gl_type`:: тип данных.
`shader_file`:: имя файла шейдера.
`needs_demosaic`:: `true` / `false`.
`bayer_pattern`:: `RGGB`, `GRBG`, `GBRG`, `BGGR`.

=== Шейдер

GLSL 330 core. Доступны uniform-ы:

`tex`:: текстура с сырыми данными.
`image_width`, `image_height`:: размеры.
`effective_bits`:: эффективные биты.
`demosaic_mode`:: режим демозаики.

== Добавление нового формата

. Создать `formats/<name>.fmt` и `formats/<name>.glsl`.
. Запустить программу с `-f <name>`.

== Сохранение

При `-s <prefix>` кадры накапливаются в памяти и сохраняются при достижении `-b` или по `-t` секунд. Имена: `<prefix>_NNNN.raw`.

== Сборка

Meson:
[source,bash]
----
meson setup builddir
cd builddir
ninja
----

Make:
[source,bash]
----
make
----

CMake:
[source,bash]
----
cmake -S . -B build
cmake --build build
----

== Зависимости

* Clang или GCC с поддержкой C23/GNU23.
* GLFW 3.x.
* OpenGL 3.3+.

== Ограничения

* Только IPv4.
* Один поток (один SSRC).
* Без шифрования.
