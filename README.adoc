= RTP Viewer — приём, анализ и отображение несжатого RTP видео
:toc: macro
:toclevels: 3
:source-highlighter: highlightjs

toc::[]

== Описание

Программа принимает RTP-пакеты по UDP (RFC 4175), собирает кадры и отображает их в окне OpenGL 3.3 Core. 
Поддерживаются различные пиксельные форматы, настраиваемые через внешние файлы в папке `formats/`.
Встроенная аналитика: гистограммы (линейная/логарифмическая шкала, CDF), выделение областей, инспектор пикселей и карта градиента.
Запись сырых кадров ведется в отдельном потоке с пулом буферов, чтобы не блокировать рендеринг.

Также поддерживается воспроизведение заранее записанных `.raw` файлов.

== Архитектура

* Модульная структура (`app/`, `source/`, `render/`, `analysis/`, `save/`, `control/`, `log/`, `util/`).
* Основной поток: ввод, приём пакетов (или чтение файла), рендеринг.
* Фоновый поток: сохранение кадров на диск (Saver). Используется пул буферов с одной непрерывной аллокацией памяти для избежания фрагментации и задержек.

== Аргументы командной строки

Обязательные:

`-x <width>`:: ширина видео (пиксели).
`-y <height>`:: высота видео.
`-f <format>`:: имя формата (`gray8`, `rgb888`, `bayerRGGB` и т.п.).

Источник (один из):

`-p <port>`:: UDP-порт для приема RTP (IPv4).
`-i <file>`:: воспроизведение `.raw` файла (зациклено).

Опциональные:

`-e <bits>`:: эффективные биты для `gray16` (по умолчанию 16).
`-s <prefix>`:: префикс имён файлов для сохранения сырых кадров.
`-b <N>`:: количество кадров в одном файле (по умолчанию 500).
`-t <seconds>`:: интервал сохранения в секундах (0 — только по количеству).
`-l <logfile>`:: файл для логов с метками времени.
`-o <dir>`:: директория сохранения raw-файлов и скриншотов (по умолчанию текущая).
`-S`:: включить сглаживание (GL_LINEAR) при старте.
`-V`:: показать версию.
`-h`:: справка.

== Горячие клавиши

=== Отображение и навигация
`1`:: переключить сглаживание (LINEAR/NEAREST).
`Space`:: Пауза / возобновление отображения и анализа.
`0`:: сбросить масштаб и позицию (zoom/pan).
`Колесо мыши`:: масштабирование (zoom) к курсору.
`СКМ (зажать и тянуть)`:: панорамирование изображения.
`Двойной клик ЛКМ`:: полноэкранный режим.
`F1`:: показать окно справки.

=== Анализ
`H`:: включить/выключить оверлей гистограммы.
`Ctrl+H`:: переключить шкалу гистограммы (линейная / логарифмическая).
`C`:: включить/выключить оверлей CDF (кумулятивная функция).
`F`:: режим градиента (Sobel). В заголовке окна отображаются метрики резкости (LapVar / Tenengrad) для текущего выделения или всего кадра.
`I`:: инспектор пикселя (координаты, значение, цвет). 
`ЛКМ (зажать и тянуть)`:: выделить прямоугольную область. Гистограммы, CDF и метрики резкости пересчитываются только по этой области.
`ПКМ` или `Esc`:: снять выделение.

=== Запись и скриншоты
`S`:: сохранить скриншот в формате PNG (в оригинальном размере кадра, без UI-оверлеев).
`R`:: включить/выключить запись сырых кадров (raw).
`W`:: принудительно сохранить накопленные кадры (flush) и закрыть текущий файл.
`E`:: включить/выключить маркеры насыщения (undershoot — синий, overshoot — красный).

== Форматы

Каждый формат описывается двумя файлами в папке `formats/`:

. `formats/<name>.fmt` — конфигурация.
. `formats/<name>.glsl` — фрагментный шейдер.

=== Файл `.fmt`

Формат — пары `ключ = значение`, комментарии начинаются с `#`.

`bytes_per_pixel`:: размер пикселя в байтах.
`gl_internal_format`:: внутренний формат OpenGL (например, `GL_RED`, `GL_RGB8`, `GL_R16`).
`gl_format`:: формат данных (`GL_RED`, `GL_RGB`).
`gl_type`:: тип данных (`GL_UNSIGNED_BYTE`, `GL_UNSIGNED_SHORT`).
`shader_file`:: имя файла шейдера.
`needs_demosaic`:: `true` / `false`.
`bayer_pattern`:: `RGGB`, `GRBG`, `GBRG`, `BGGR`.

=== Шейдер

GLSL 330 core. Доступны uniform-ы:

`tex`:: текстура с сырыми данными.
`image_width`, `image_height`:: размеры кадра.
`effective_bits`:: эффективные биты (из аргумента `-e`).
`demosaic_mode`:: режим демозаики.

== Сохранение

=== Скриншоты (PNG)
При нажатии `S` изображение рендерится в offscreen FBO размером `WxH` (без letterbox'а и оверлеев) и сохраняется в директорию `-o` под именем `screenshot_YYYYMMDD_HHMMSS.png`.

=== Сырые кадры (RAW)
При `-s <prefix>` или включении записи клавишей `R`, кадры накапливаются в памяти и сохраняются при достижении `-b` или по `-t` секунд.
Имя файла: `<prefix>_<YYYYMMDD_HHMMSS>_<WxH>_<format>_<NNNN>.raw`.

== Сборка

Make (MinGW / GCC):
[source,bash]
----
make
----

Для сборки релиза (создание zip-архива с exe, форматами и .bat-файлом):
[source,bash]
----
make publish
----

== Зависимости

* GCC или Clang с поддержкой C23/GNU23 (`-std=gnu2x`).
* GLFW 3.x.
* OpenGL 3.3+.
* Windows: `-lws2_32` для сокетов.

== Ограничения

* Только IPv4 (для сетевого режима).
* Один поток для рендеринга и UI (Saver вынесен отдельно).
* Без шифрования и RTCP.
